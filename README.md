# Numerical_differentiation-integration_Experiment

    Numerical experiment to compare the diferentiation of a tracker (with given experimental data from a mechanical experiment on a plane) with numerical methods.
    It also integrates the previously calculated velocities, to smooth it and get the position of the particle.
    Made as a mini project for the class *Herramientas Computacionales*
